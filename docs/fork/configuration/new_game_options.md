# New-game options

The startup menu has two pages. L/R changes page, Up/Down selects a row,
Left/Right changes a value, and START confirms.

Page 1: Mode, Faint Rule, Player EVs, Random Encounters.
Page 2: Randomizer Max Gen, Random Abilities, Reusable TMs.

Modes cycle through NUZLITE, NUZLOCKE and CUSTOM. NUZLITE is selected initially.
NUZLITE uses one death per whiteout; NUZLOCKE uses death on faint. Both lock
battle style to Set, disable player EV gains, enable randomized encounters and
abilities, and default to Generation 9. Their visible rule rows are locked
except Randomizer Max Gen.

CUSTOM allows editing every visible rule. Its visible defaults are faint rule
OFF, player EVs OFF, randomized encounters OFF, random abilities OFF, Generation
3, and reusable TMs OFF. Reusable TMs also default to OFF in both challenge modes.

In every mode the hidden rules are fixed: catch limit ON, level cap ON, items
in battle OFF, Infinite Rare Candy ON, Infinite Repel ON, item randomizer ON,
and Mega Evolution ON. These settings remain active without appearing as rows.

These choices apply to new games.
