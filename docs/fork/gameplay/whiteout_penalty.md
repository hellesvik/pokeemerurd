# Whiteout and faint penalties

The new-game menu supports two loss rules:

- **1/WHITEOUT** marks one random non-egg Pokémon in the party as a
  soft-nuzlocke Pokémon. It remains fainted and cannot be healed.
- **ON FAINT** marks each player Pokémon as lost when it faints, leaving it
  permanently fainted immediately.

**OFF** leaves the game's normal whiteout and faint behavior unchanged. These
settings are configured in [New-Game Feature Options](../configuration/new_game_options.md).
